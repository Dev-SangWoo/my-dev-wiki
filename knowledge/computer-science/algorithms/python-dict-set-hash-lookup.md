# Python dict·set과 해시 조회

## Current Understanding

1. `dict`는 **해당 값이 몇 번 있는지가 중요할 때, 즉 카운팅할 때 필요**하다고 이해한다.

2. `set`은 **같은 배열에서 중복을 제거하고, 해당 값이 이 배열 안에 들어 있는지가 중요할 때 필요**하다고 이해한다.

3. `in`은 `if` 조건에서도 사용할 수 있고, 이미 본 값인지 확인하는 문제에서 `set`과 함께 사용할 수 있다.

4. 두 배열의 공통 값을 찾을 때 한쪽 배열을 `set`으로 바꿔두고 다른 배열을 순회하면서 존재 여부를 확인하는 방식으로 풀 수 있다고 이해한다.

## Quick Recall

```text
등장 횟수 → dict
이미 봤는지 / 존재하는지 → set
list의 in → O(N)
set의 in → 평균 O(1)
두 배열 비교: O(N×M) 대신 set을 만들면 평균 O(N+M)
```

## Open Questions

- `set` 조회가 빠른 핵심은 중복 제거가 아니라 해시 기반 평균 O(1) 조회라는 점을 문제를 더 풀면서 확실히 굳힐 필요가 있다.
- 두 배열 크기가 각각 `N`, `M`일 때 `O(N×M)`이 `O(N+M)`으로 줄어드는 계산 감각을 더 익힐 필요가 있다.
