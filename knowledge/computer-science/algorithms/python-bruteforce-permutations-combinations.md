# Python 완전탐색, 순열·조합과 경우의 수

## Current Understanding

1. 숫자 4개에서 2개씩 골라 확인하는 문제는 **2중 for문 걸리면 되지 않을까**라고 접근했다. 같은 원소를 고르거나 같은 조합을 두 번 확인하지 않으려면 안쪽 반복문을 `i + 1`부터 시작하는 방식으로 이해했다.

2. `for j in range(i)` 형태도 **뭔가 직관적으론 n^2이 안 될 것 같지만 결국 이것도 n^2일 것 같음**이라고 판단했다. 실행 횟수가 삼각형처럼 줄거나 늘어도 `O(N²)`이 될 수 있다는 점을 확인했다.

3. 회장과 부회장을 고를 때는 **회장과 부회장이 다르니까** 순열이라고 판단했다. 직책 없이 팀원을 뽑을 때는 조합이라고 판단했다.

4. 조합에서 순서가 다른 경우를 추가로 곱하는 것으로 처음 계산했지만, 같은 사람들끼리 순서만 바뀌면 같은 조합이므로 중복된 순서의 수만큼 **나눠야 한다**는 점으로 교정했다.

5. `combinations(arr, 3)`로 가능한 조합을 직접 순회하면서 `sum(i) == 10`인 것만 출력했다. 목표값과 가까운 세 수를 고르는 문제에서도 `abs(target - sum(i))`로 차이를 계산하고 더 작으면 갱신하는 코드를 작성했다. 가장 가까운 조합과 합까지 구할 때는 **best_combination = i, best_sum = current_sum이지 않을까?**라고 연결했다.

6. `permutations(arr, 3)`은 `combinations(arr, 3)`보다 **늘어날 것 같지만 결국엔 미미할 것 같은데 똑같이 n^3일 것 같음**이라고 판단했다. 순열이 3!배 더 많은 경우를 확인해도 둘 다 3개 고르기가 고정된 경우 `O(N³)`이라는 점을 확인했다.

7. 종합 복습에서 회장·부회장 선발과 직책 없는 대표 선발의 순열·조합을 처음에는 반대로 골랐다. 이후 메달 세 자리 선택에서 **순열**이라고 올바르게 판단했지만 150가지로 잘못 계산했다. 다시 회장·부회장·총무 세 자리를 4명 중에서 뽑는 문제에서는 **순열 이겠죠? 4 3 2 = 24**라고 답해, 역할이 다르면 순열을 선택하고 남은 인원을 곱해 계산하는 데 성공했다.

## Quick Recall

```text
완전탐색 → 가능한 경우가 충분히 작으면 전부 확인
순열 → 직책처럼 순서/역할이 중요
조합 → 선택 자체가 중요, 순서만 다른 것은 같은 경우
2개 선택 → O(N²)
3개 선택 → O(N³)
N개 중 3개 순열과 조합 → 반복 횟수는 다르지만 둘 다 O(N³)
더 좋은 답을 발견 → 최솟값과 해당 데이터 함께 갱신
```

## Open Questions

- 서로 다른 직책을 부여하는 순열은 4×3×2=24처럼 계산할 수 있게 되었다. 다만 조합과 순열이 섞인 문제에서 둘을 일관되게 구분하고 조합의 나눗셈까지 정확히 적용하는지는 복습이 필요하다.
- 반복문 겉모양만 보고 `O(N)`이라고 판단하지 않고, `combinations()`가 만드는 전체 경우의 수를 먼저 계산하는 감각을 복습할 필요가 있다.
