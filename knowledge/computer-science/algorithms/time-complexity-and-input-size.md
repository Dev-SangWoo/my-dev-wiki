# 시간복잡도와 입력 크기로 풀이 판단하기

## Current Understanding

1. 시간복잡도는 **시간 안에 코드 문제가 풀려야 돼서** 확인한다.

2. 반복문이 연속으로 나오면 더하는 관계로 보고, **연속된 건 더하기라 신경 크게 X**, 중첩 반복문은 곱하는 관계라 **복잡도 커지기 쉬우니까 조심**한다고 이해한다.

3. `N = 100,000`인데 풀이가 `O(N²)`이라면 **다르게 풀어야겠다**고 생각한다.

4. `i *= 2`처럼 두 배씩 커지거나 `i //= 2`처럼 반절씩 줄어드는 반복은 서로 방향만 다를 뿐 같은 형태로 보고 `O(log N)`으로 이해한다. 특히 반으로 줄어드는 코드를 보고 **반절씩 줄어들잖아 사실상 위에꺼랑 똑같아 보이는데?**라고 연결했다.

5. 다음과 같은 반복에서는 안쪽 반복 횟수가 `0 + 1 + 2 + ... + (N - 1)`이 되어 전체가 `N(N - 1) / 2` 정도이고, 따라서 `O(N²)`으로 본다.

```python
for i in range(n):
    for j in range(i):
        pass
```

6. 바깥 반복이 `O(N)`이고 그 안에서 `O(log N)` 반복이 매번 실행되면 서로 중첩되어 `O(N log N)`이 된다고 이해한다.

## Quick Recall

```text
연속 반복 → 더하기
중첩 반복 → 곱하기
×2 / ÷2 반복 → O(log N)
N이 큰데 O(N²) → 다른 풀이를 찾아야 하는지 먼저 의심
```
