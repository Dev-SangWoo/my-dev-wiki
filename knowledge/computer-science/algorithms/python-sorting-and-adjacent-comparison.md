# Python 정렬과 인접 비교

## Current Understanding

1. `sorted()`는 **원본 안 바꿈**으로 이해한다. 정렬된 새 값을 받아 쓰는 방식이고, `.sort()`는 원본 리스트를 바꾸는 방식으로 구분한다.

2. `key=lambda x: (-x[1], x[0])`은 **1번 위치에 있는 건 내림차순으로 정렬 후, 같은 건 0번 자리에 있는 건 오름차순으로 정렬**하는 방식으로 이해한다.

3. 최소 차이 문제에서는 **정렬했으니까 최소 값이 인접한 값에서만 나옴**으로 이해하고, 정렬 후 인접한 값끼리만 비교하면 된다고 판단한다.

4. Python 일반 정렬의 시간복잡도는 `O(N log N)`으로 기억한다.

5. `i + 1`을 사용하는 순회에서 IndexError가 나면 **결국 반복수를 줄이던가, 이전으로 하던가**라고 이해한다. 즉 `range(len(arr) - 1)`로 마지막 반복을 줄이거나, `range(1, len(arr))`에서 현재 값과 이전 값을 비교하는 방식으로 처리한다.

## Quick Recall

```text
sorted(arr) → 원본 유지 + 새 정렬 리스트
arr.sort() → 원본 변경
key=(기준1, 기준2) → 여러 정렬 기준
(-점수, 이름) → 점수 내림차순 + 이름 오름차순
최소 차이 → 정렬 후 인접 비교
i+1 사용 → 마지막 반복 범위 주의
Python 정렬 → O(N log N)
```
