# Python 리스트·문자열 순회와 슬라이싱

## Current Understanding

1. `enumerate()`는 **인덱스랑 값 둘 다 활용하고 싶을 때** 쓴다고 이해한다.

2. 문자열과 리스트는 `for`로 한 번 순회하면서 필요한 값을 계산하는 패턴을 사용할 수 있다고 이해한다.

3. `word[::-1]`처럼 뒤집는 슬라이싱은 한 번 사용할 때는 편하지만, 길이 `N`인 값을 `N`번 반복해서 뒤집으면 `O(N²)`까지 커질 수 있으므로 **큰 값들을 거꾸로 바꿀 때 슬라이싱을 반복해서 쓰는 건 조심**해야 한다고 이해한다.

4. 문자열 팰린드롬은 원본과 `[::-1]` 결과를 비교해서 확인할 수 있다고 이해한다.

5. 문자열에서 필요한 문자만 모을 때 리스트에 `append()`하고 마지막에 `"".join(...)`으로 합치는 코드를 사용할 수 있다.

## Quick Recall

```text
enumerate → 인덱스 + 값이 둘 다 필요할 때
[::-1] → 뒤집기용 슬라이싱
슬라이싱을 반복문 안에서 큰 데이터에 반복 적용 → 복잡도 커질 수 있으니 주의
```
