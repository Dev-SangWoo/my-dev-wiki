# Python 리스트·문자열 순회와 슬라이싱

## Current Understanding

1. `enumerate()`는 **인덱스랑 값 둘 다 활용하고 싶을 때** 쓴다고 이해한다.

2. 문자열과 리스트는 `for`로 한 번 순회하면서 필요한 값을 계산하는 패턴을 사용할 수 있다고 이해한다.

3. `word[::-1]`처럼 뒤집는 슬라이싱은 **`[::-1]` 자체가 문자열 길이 `N`만큼 작업을 먹고 있는 것**으로 이해하고, 길이 `N`인 값을 `N`번 반복해서 뒤집으면 `O(N²)`까지 커질 수 있으므로 **남발해서 사용하면 시간복잡도가 커질 수 있으니 조심**해야 한다고 이해한다.

4. 문자열 팰린드롬은 원본과 `[::-1]` 결과를 비교해서 확인할 수 있다고 이해한다.

5. 문자열에서 필요한 문자만 모을 때 리스트에 `append()`하고 마지막에 `"".join(...)`으로 합치는 코드를 사용할 수 있다.

6. 문자열을 반복해서 `+`로 붙이면 매번 새로운 문자열이 생길 수 있고, 그것이 **자원 낭비가 될 수 있으니**, 조각들을 리스트에 모아두었다가 **원할 때 한 번에 합치는 방식이 더 안전하다**고 이해한다.

## Quick Recall

```text
enumerate → 인덱스 + 값이 둘 다 필요할 때
append + join → 문자열을 반복 생성하지 않고 모아서 한 번에 합치기
[::-1] → 길이 N만큼 드는 뒤집기용 슬라이싱
슬라이싱을 큰 데이터에 반복 적용 → 복잡도 커질 수 있으니 주의
```
