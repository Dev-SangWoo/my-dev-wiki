# Review Knowledge Workflow

사용자가 자신의 개발 지식을 복습하거나 약한 부분을 점검하려 할 때 사용한다.

항상 루트 `AGENTS.md`의 Core Rules를 우선한다.

## Procedure

1. 복습 범위를 정한다. 사용자가 특정 범위를 말하지 않았다면 최근 또는 관련 지식에서 적절한 범위를 선택한다.
2. 관련 지식 파일의 `Current Understanding`, `Open Questions`, `Understanding Timeline`을 우선 읽는다.
3. 일반적인 교과서 문제보다 사용자의 실제 이해와 과거 혼동을 기반으로 복습한다.
4. 다음을 특히 우선한다.
   - 아직 남아 있는 `Open Questions`
   - 과거에 잘못 이해했다가 교정된 부분
   - 사용자가 비슷한 개념을 혼동했던 부분
   - Connections상 중요하지만 설명이 약한 연결
5. 정답을 바로 보여주기보다 사용자가 먼저 자신의 언어로 설명할 기회를 준다.
6. 답변을 확인한 뒤 필요한 사실 교정을 대화에서 수행한다.
7. 복습 과정에서 사용자의 이해가 의미 있게 바뀌었다면 `store.md` workflow를 따라 지식을 갱신한다.

## Goal

복습의 목적은 문서를 다시 읽게 하는 것이 아니라 **사용자가 스스로 기억을 재구성하고 설명할 수 있게 하는 것**이다.
